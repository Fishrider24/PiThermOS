OpenWeatherMap Key:

OpenWeatherMap is an api that grabs local weather data. Go to https://home.openweathermap.org/users/sign_up to get an API Key. Save the Key to your records and input it into the box below.
Then go to https://openweathermap.org and search your City. If there is only one city shown use it.
Otherwise find a different city nearby that has only one choice. Sometimes city names are used all over the world.







Temperature Swing:

Temperature swing is the Temperature at which the Thermostat turns on and off outside the Setpoint. Recommended no more that 2 degree swing.

Influx DB:

If you want to Graph Inside and Outside Weather. Programmed to track temp_inside, hum_inside, setPoint, outtemperature, hum_local. Will need to reboot thermostat after changing.









MQTT:

Can be used to control Furnace, Whole house Humidifier over wifi to ESP32. Will need to reboot thermostat.





Reboot Thermostat:

There is a five minute delay programmed to make the Thermostat wait five minutes between when the furnace/air shuts off and when it can start again.
